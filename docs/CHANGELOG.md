### 主题（设置 › 主题）
- 10 套主题：白天 5（蓝图 / 白瓷 / 砂岩 / 钢与雾 / 象牙金）、夜间 5（曜石账本 / 石墨与铜 / 午夜翡翠 / 电路靛蓝 / 深海），白天和夜间各选一个。
- 模式三选一：按日出日落自动 / 一直白天 / 一直夜间。自动模式服务端按经纬度算日出日落（NOAA 算法，误差 < 2 分钟），客户端到点自动换、不刷新。
- 位置默认 Austin，可"用我的位置"一键定位或手填经纬度；页面显示今天的日出日落。
- 全站颜色改成 CSS 变量（`bg-surface / text-muted / bg-accent …`），写死的颜色全部清掉；主题色值只在 `packages/core/src/themes.ts` 一处。
- 选主题卡片即时预览，保存才生效；设置存 `agents.settings.theme`。

### 字体
- 英文标题 / 正文 Manrope，数据 DM Mono（`next/font` 自托管）；中文 MiSans（小米，免费商用），按 unicode-range 切片自托管（`scripts/fetch-misans.mjs` 生成，300 片 6.6 MB，页面只下用到的片）。

### 联系人（新模块）
- 表：`organizations`（公司）、`contacts`（人）、`deal_parties`（交易 × 人或公司 × 角色 × 我方/对方/中立）、`contact_links`（紧密关系）。类型 = 身份（contacts.kind），角色 = 在某笔交易里的位置（deal_parties.role），分开存。
- 总表 `/contacts`：人 + 公司一张表，9 类页签，搜索（姓 / 名 / 地址 / 电话 / 职位 / 公司 / 微信），表格 ⇄ 卡片，添加联系人 / 添加公司面板。
- 表单交互：类型联动所属公司列表，下拉底部固定"+ 添加公司"可当场新建；页签决定默认类型；邮箱 `@` 后灰字补全（Tab）；姓名首字母自动大写；10 位美国号码自动 3-3-4；首选联系方式默认微信；职位候选 = 用过的按频率 + 房产预设；常用标签一行点选 / 再点删除；来源库预设 + 手输自动进库；同时只开一个面板，点外面或切换时有未保存内容必须选 保存 / 放弃 / 继续。
- 详情页 `/contacts/[id]`：左栏 头像卡 / 联系方式（带复制）/ 紧密关系（夫妻、父母、子女… 一对存一行，另一方自动反向）/ 备注；右栏 相关交易（阶段色条、角色、阶段、下一节点）、相关联系人（同一交易里的人，不列服务商，卡片带对方的紧密关系）。
- 排序强度（core 纯函数）：阶段越初级越强（lead 70 … closed 5 / terminated 0）+ 时间线（今天 10 分，一年衰减到 0）；相关联系人再每笔共同交易 +5。
- 公司详情 `/contacts/org/[id]`：资料、这家公司的人、参与的交易。
- 交易详情新增"各方"选项卡：按我方 / 对方 / 中立分组，添加参与方（角色自动定方向）、移除。
- 交易阶段配色统一：`STAGE_COLORS` 一处定义，全站用 `StageBar / StageDot / StageBadge`。
