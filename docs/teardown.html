Wise Agent 拆解手册

把你每天在用的 Wise Agent 从头到尾走了一遍：10 个一级菜单、45 个页面、全部弹窗和设置项。这份手册记录它的信息架构、每个模块的功能清单、底层数据对象和核心 user flow，再列出痛点，最后给出你自己那个 AI-native 版本的蓝图。配套的 Wireframe 画布单独交付。

抓取方式 登录态实机浏览，viewport ≈ 790px覆盖 10 菜单 / 45 页面 / 12 弹窗数据 全部样例化，不含客户信息

00结论

一句话：Wise Agent 是一个"以 Checklist 模板为引擎的老牌 CRM"，值钱的是引擎，不值钱的是壳。

  1. 真正的核心只有一个：Checklist 模板引擎。 一个交易 = 一份模板实例，模板里的 Critical Dates 决定了几十个任务的到期日（"N days before/after 某个日期"），任务再联动 Task List、日历和触发器（Email / Text / Drip / Team Alert）。你做的 Seller / Buyer / Lease Listing 模板就是你的 SOP，这套东西必须完整迁移到新产品里。
  2. 联系人层是"通讯录 + 活动日志"，不是关系管理。 Activity 只自动记录字段变更和 checklist 变化，真正的沟通内容（电话说了什么、微信聊了什么）全靠手动 Call Note。20 个 section 平铺，没有一句"这个人现在处于什么状态、下一步该干什么"。
  3. 信息架构过时： 菜单叫 Transactions，页面叫 Checklists；Calendar 没有独立页面只在 Dashboard 上；Properties 和 Checklist 之间只是弱关联；45 个 Integrations 开关堆在一个页面。整站是 ASP 时代的页面 + Bootstrap 皮肤，一屏信息密度低，Checklist Summary 单页高度超过 20 屏。
  4. AI 几乎为零： 只有 GPT 写邮件助手；AI Bot 要另买 WiseText 号码；没有摘要、没有自动抽取合同日期、没有自动填表、没有"今天该做什么"。
  5. 你的机会点： 用 4 个核心对象（Contact · Property · Deal · Timeline）+ 1 个自动化引擎重建，把"录入"变成"自动抽取"，把"提醒"变成"主动建议"，把"英文邮件"变成"中英双语 + 微信/短信统一收件箱"，再加一个真正的 iPhone app。不要复制它 10 个菜单，复制它的 SOP 引擎。

  • Alert 可挂在 Event / Task / Call 上（邮件或短信提醒）

06新产品蓝图

定位：一个人的 AI 交易操作系统（self-use first）。服务对象是 DFW 华人买卖/租赁客户，流程是 Texas TREC 合同流程，沟通渠道是微信 + 短信 + 邮件。先把你自己的 5 套模板跑起来，再考虑产品化。

设计原则

  • 4 个对象 + 1 个引擎：Contact · Property · Deal · Timeline，加 Automation（触发器 → 动作）
  • 录入变抽取：合同、名片、微信截图、语音都是输入，AI 负责结构化
  • 提醒变建议：系统每天主动给出"最要紧的 3 件事"和一键动作
  • 手机优先：80% 操作在 iPhone 上 30 秒内完成；桌面端做重活（模板、报表、批量）
  • 双语：UI 中文为主、术语英文；客户面材料可中/英切换

从 Wise Agent 带走的

  • 5 套模板的日期、字段、任务规则（导出后做成 playbook JSON）
  • 联系人 CSV（含配偶、家人、生日、分类、来源）
  • Rank / Status / Source / Category 的现有取值
  • 每笔交易专属收件邮箱 + Hot List 的思路
  • Transaction Portal 的思路（客户看进度）

技术选型建议（Windows 开发机 + iPhone 测试 + Claude Code）

  • App：Expo（React Native）+ Expo Router；iOS 打包走 EAS Build 云端，不需要 Mac；同一代码出 Web 桌面端。
  • 后端：Supabase（Postgres · Auth · Storage · Edge Functions · Realtime），schema 直接照第 3 节的对象建表。
  • AI：Claude API 做抽取 / 摘要 / 草稿；PDF 用 pdf.js 转文本或直接送多模态；表单填充用 pdf-lib 写 TREC 可填 PDF。
  • 集成：Twilio（短信 / 通话记录）· Google Gmail & Calendar API · Expo Notifications（推送）· 微信没有 API，用"分享到 app"和截图 OCR 归档。
  • 迁移：Wise Agent 联系人走 Export CSV；模板用 Print/Email Summary 或人工整理成 JSON（5 套，一次性活）。
